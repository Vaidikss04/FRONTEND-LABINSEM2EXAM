# 🏨 React RoomCard Component

## 📌 Project Description
This project demonstrates a reusable React component called `RoomCard`. It displays hotel room details using **Props** in React.

## 🚀 Features
- Reusable RoomCard component.
- Passes data using React Props.
- Displays room number, room type, and price.
- Displays three different room cards.
- Simple and clean UI.

## 🛠️ Technologies Used
- React.js
- JavaScript (JSX)
- CSS
- HTML

## ⚙️ How to Run

1. Clone the repository:

   ```bash
   git clone <your-repository-link>
   ```

2. Navigate to the project folder:

   ```bash
   cd RoomCard
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

## 📚 React Concept Used

**Props:** Props are used to pass data from a parent component to a child component.

Example:

```jsx
<RoomCard roomNumber="101" type="Single" price={1000} />
```
